Ember Court is an original turn-based duel card game: you play creatures and spells from four suits (Ember, Tide, Thorn, Gale) against the AI Cinder Warden, combining Steam, Mend, Leech and Swift keywords to take the Warden's 30 life to zero.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in a desktop browser.
